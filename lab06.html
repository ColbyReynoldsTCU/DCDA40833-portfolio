Lab 6: Interactive Web Map

Custom Mapbox basemap + hometown locations + Python/Folium map

Lab 6 Overview

For Lab 6, I had to design a custom Mapbox basemap, create a dataset of important places from my hometown, and use Python and Folium to build an interactive map. I then had to add the finished map and my written reflection to my portfolio page and make sure everything worked correctly on GitHub Pages.

Interactive Map

This map uses a custom basemap I designed in Mapbox Studio and a dataset of meaningful locations across Colorado. The locations were geocoded with the Mapbox Geocoding API and mapped using Python + Folium.

Broader Reflections

My original goal for my MapBox style was to create a cartoon/adventure cartoon style, something that you might see in a video game or comic book. I wanted it to feel different than the traditional maps and also fit the outdoor Colorado theme. Unfortunately, after several attempts it just was not turning out the way that I had intended. While I got it to match the style I was going for, it just was too hard to read and made the map feel like I was on an old DS game. So, I decided to go for something that was a little more minimalistic and easier for the user to read. I wanted it to be like a common map but wanted to add some of my own style points like borders and slightly different colors.

The biggest cartographic challenge was designing multiple scales. One issue that I was running into was that every time I zoomed in everything just reverted to black and white which totally defeated the purpose of me creating my own style. Once I was able to conquer that, I ran into some issues with my outlines and text. I was finding that as I zoomed in on the map, the text and the outlines were too large and getting in the way of some of the streets and locations, making it look unprofessional. Through trial and error, I was able to fix these small issues and my map functions and look good.

I didn’t run into issues with the coding side of things. Luckily, we ran through exactly how to do this in class, so I was able to easily look back on our in-class activity and troubleshoot where necessary. I used AI to help support and troubleshoot; it especially helped with the python code and getting my locations geocoded. Overall, it was a smooth process.
