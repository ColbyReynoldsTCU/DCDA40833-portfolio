AI-assisted development experiments (Portfolio + Python)

Lab 5 Overview

For Lab 5, I had to use AI as a coding assistant and think critically about how AI can help with development. The lab required me to build or improve something with AI support, explain what the AI did versus what I did, comment key parts of the code to show my understanding, include a screenshot or demo, and write a reflection on the process.

Experiment A: Portfolio Enhancement

I used AI to help me add a responsive navigation menu (hamburger menu on mobile) and CSS transitions/animations for smoother interaction.

My prompts

Prompt 1:
I have a portfolio website with a sticky nav that is currently a nav,ul,li,a list. 
I want a responsive navigation bar where on mobile it turns into a hamburger menu that opens/closes when clicked.
Please keep my current colors and overall look. My nav background is #3d1461 and my links are white.

Prompt 2:
Can you add simple CSS transitions/animations so the nav links feel smoother (hover transition) and the hamburger icon animates into an “X” when open?

Prompt 3:

Keep the comments simple.

  • I updated the JavaScript to also close the menu when I click a link and when the screen resizes back to desktop size.

Critical Reflection

1. The AI generated a few different things for this assignment. The first thing that it generated was the basic code to add the hamburger menu to my webpage for mobile devices. It also added the CSS to help style the hamburger menu. I had to add JavaScript to help make the hamburger menu function, which the AI wrote. Lastly, it helped me debug the Python for Colab, which I already had a file for cleaning Excel sheets from my Python class last semester, but some things were missing and I had to have AI debug for me. It also created a CSV file with simulated data to run in Python.

2. The HTML code that it added was mostly stuff I had seen in my classes before. Some things that I had to learn or were new were some of the things for the hamburger menu, the three lines that represent the button, and the ul which is an id that allows the JavaScript to find it. The CSS allows the button to be hidden in desktop view and the media query allows it to appear on smaller screens. In the JavaScript it has the open class which allows the button to be seen. The JavaScript also enables some animation features. Basically, when the button appears, it can flip it open and closed. I do not fully understand all of the CSS and JavaScript although I do pretty much understand how it works. Luckily, I am using JavaScript in another class right now so I have learned a little bit about how it works alongside CSS and HTML.

3. I had to modify the CSS because the first time the AI gave it to me it changed the style of my HTML so I had to ensure it matched the templates that we are using. I already had the Python code from my data visualization Python class last semester, but it did have some bugs and a couple things that the AI helped me to add.

4. The AI was very helpful. The nice thing is that I can have it explain anything I do not understand and it will. Additionally, it makes things faster as I can give it what I already have, along with the data I am using, and it will integrate both. This simplified the Colab notebook I had.

5. The AI seems to be problematic only when I did not give it the full story. For example, when it did not know I already had CSS styling it created its own, but then when I gave it the CSS styling I already had, it matched that in its new code.

6. I think there are potential problems when it comes to security with AI. Ultimately, the person is the one who should decide what and how things are done. The AI should be the one who does the grunt work like the actual coding.

7. I think it definitely helps me develop as a programmer. I believe I do not learn as much as someone who is learning to code without using AI, but I can also get a lot more work done than someone who is coding without using AI.

8. I think academically it is important to say that you used AI and to what extent that you used it. Professionally, I think companies already have AI integrated into their systems and want employees to be using AI to automate and speed up work and to reduce costs, but there needs to be someone who is responsible for it, as if it were another employee.

9. My guidelines are that I never use any personal data and if I am building something I have to know what I can see, versus what people can see when they view or use my work or software. I try to prompt as much as possible to ensure it is doing exactly what I want it to do.

My Vibe Coding Guidelines

  • I only use AI-generated code if I can explain it in my own words.
  • I test changes immediately and commit before/after big edits.
  • I add comments that honestly reflect my understanding level.
  • I cite AI assistance and distinguish what AI wrote vs. what I changed.
