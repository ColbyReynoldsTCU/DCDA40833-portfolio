Semester Reflection

What I learned: Over the course of these labs, I learned more about how digital culture and data analytics connect through different kinds of projects. In Lab 2, I learned how to look at AI tools more critically instead of just using them for quick answers. In Lab 3, I practiced slowing down and really analyzing how a visualization communicates information. In Lab 4, I got more experience using Tableau to find patterns in data and turn them into something interactive. In Lab 5, I learned more about using AI as a coding helper while still making sure I understood what the code was doing. In Lab 6, I learned how mapping, design, and Python can all work together in one project.

Challenges I overcame: The biggest challenges came when projects had a lot of moving parts. Some labs were not just about writing one thing, but about combining design, analysis, code, and reflection all together. I also had to make sure everything worked correctly in my portfolio and that each page connected well with the others. With the mapping lab, there were some small issues with design choices, scaling, and getting everything to display the way I wanted. Through trial and error, going back through class examples, and testing things step by step, I was able to work through those problems.

How I grew: I think I grew most in how I approach digital projects as a whole. At the start, I mainly thought about finishing the task, but over time I started thinking more about design, audience, usability, and how information is presented. These labs helped me see that digital culture and data analytics are not just about technical skills. They are also about making thoughtful choices, asking better questions, and communicating clearly. I also became more confident with GitHub, building web pages, and using tools like AI, Tableau, Mapbox, and Python in a more practical way.

Looking ahead: Moving forward, I think these skills will be useful in both school and professional work. Being able to build a website, analyze a visualization, work with data tools, and explain my process clearly are all skills that can carry over into a lot of different jobs. I also think learning how to use AI the right way will be very important in the future. This portfolio gave me a place to practice both technical and creative work, and it helped me build projects that I can continue to improve later on.
